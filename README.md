## What this entry does

`main.ts` (Node 22) writes exactly one original line — the most useless
superpower imaginable, with its uselessness stated in the same breath — to
`/output/entry.txt`. The program is deterministic, uses no network, and has
no dependencies: it only creates `/output` if missing and writes the line
as UTF-8 text with no trailing newline.

## How to run

```sh

cat /output/entry.txt
```
